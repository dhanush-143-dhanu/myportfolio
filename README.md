# Dhanush Vishwanathan RK — 3D Animated Portfolio

Open `index.html` in a browser or deploy the folder to GitHub Pages.

The hero section uses `assets/hero-intro-with-audio.mp4` as the cinematic intro video. Browsers autoplay it muted; the original audio is retained in the MP4 and can be enabled with browser controls if desired.

Tech: HTML, CSS, JavaScript, Three.js CDN.
